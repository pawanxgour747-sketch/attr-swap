# Attribute Swap by Velox (26.2 port)

Build:  `./gradlew build`  (needs JDK 25, Gradle 9.5.1 wrapper: `gradle wrapper --gradle-version 9.5.1`)
Jar:    build/libs/attribute_swap_velox-1.1.0.jar

Keys: \ toggle | ; bind A (current slot) | ' bind B | [ info
Commands: /attrswap bind1 <1-9> | bind2 <1-9> | toggle | info | clear

Removed vs 1.0.3: client-side reach extension and forced attack-cooldown reset.
